Задача №13

Запрос сервиса A

Поиск провайдера: Angular проверяет таблицу провайдеров в Root. Провайдер для класса A найден.
Проверка кэша: Angular проверяет, создан ли уже экземпляр A. В кэше пусто.
Начало инициализации: Angular начинает создавать экземпляр класса A. Во время этого процесса он натыкается на строку b = inject(B). Создание A приостанавливается, так как для него сначала нужно получить B.

Разрешение зависимости B

Поиск провайдера: Инжектор ищет провайдер для класса B в Root. Находит.
Проверка кэша: Экземпляра B в кэше еще нет.
Начало инициализации: Angular начинает создавать B и натыкается на строку c = inject(C). Создание B приостанавливается.

Разрешение зависимости C

Поиск провайдера: Инжектор находит провайдер для C.
Проверка кэша: В кэше пусто.
Начало инициализации: Angular начинает создавать C и видит строку d = inject(D). Создание C приостанавливается.

Разрешение зависимости D

Поиск провайдера: Инжектор находит провайдер для D.
Проверка кэша: В кэше пусто.
Начало инициализации: Angular начинает создавать D и видит строку logger = inject(LoggerService). Создание D приостанавливается.

Разрешение базовой зависимости LoggerService

Поиск провайдера: Инжектор находит провайдер для LoggerService.
Проверка кэша: Допустим, его тоже еще нет в кэше.
Создание и Кэширование LoggerService: У LoggerService нет внутренних зависимостей. Angular вызывает new LoggerService(), кэширует его и возвращает созданный объект в класс D в переменную logger.

Развертывание стека и кэширование (Снизу вверх)

Теперь, когда самая глубокая зависимость разрешена, Angular начинает завершать создание классов в обратном порядке:
Инициализация и Кэширование D: Получив LoggerService, Angular полностью завершает создание new MyD(), сохраняет (кэширует) готовый экземпляр D в Root инжекторе и возвращает его в класс C в переменную d.
Инициализация и Кэширование C: Получив D, Angular завершает создание new C(), кэширует экземпляр C в Root инжекторе и передает его в класс B в переменную c.
Инициализация и Кэширование B: Получив C, Angular завершает создание new B(), кэширует экземпляр B в Root инжекторе и передает его в класс A в переменную b.
Кэширование A: класс A получает свою зависимость B. Angular завершает выполнение new A(), сохраняет (кэширует) экземпляр A в Root инжекторе и возвращает его в то место, откуда изначально был вызван самый первый inject(A).
